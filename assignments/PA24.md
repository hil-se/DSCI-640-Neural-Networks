PA2-4 assignment is focused on implementing gradient boosting and scaling, as well as an LSTM cell.

Programming Assignment 2 is 28% of your final grade, and Part 4 is 25% of that. This will be graded out of 7 points.




1. (1 point) Implement gradient boosting and scaling (in GradientDescent.java).

2. (2 points) Complete the LSTMNode.java code. This will involve implementing both the propagateForward and propagateBackward methods. You can add extra fields if needed (but I was able to complete with just the ones in the provided LSTMNode.java code), so you shouldn't need any more. You will also need to implement the initializeRandomly methods, which will initialize all weights and biases for the node and input edges (don't forget to add 1 to the forget gate bias).

In completing the above, none of your changes should break the unit tests in BasicTests.java, PA21Tests.java, PA22Tests.java, or PA23Tests.java. You should be able to successfully complete all the PA24TestsLSTM.java. Additionally you should be able to successfully run the GradientDescent.java program for any network and data type, example usage and parameters:
```
java GradientDescent flights_small LSTM jordan xavier stochastic 10 l2_norm 10 0.1 0.005 0.95 0.05 1.0 10
```
